## ✨ My Contributions

### 🛒 Checkout Page
A modern, responsive checkout flow added to the dashboard.

- Progress tracker (Payment → Review → Confirmation)  
- Contact & address form with validation  
- Billing vs shipping toggle  
- Multiple payment methods (Card, UPI/Wallet, Net Banking, COD)  
- Promo code validation  
- Order summary with tax, discount & totals  
- Secure checkout indicators  

---

### 🖼️ Photo Gallery
An interactive gallery module to manage and view media.

- Category filters  
- Search bar for quick lookup  
- Grid/List view toggle  
- Favorite items ❤️  
- Download option  
- Modal with Bootstrap carousel for preview  
- Load more (dynamic rendering)  
- Fully responsive

## 🔧 Installation

### Using a ready-made build (recommended)
Download the latest release from the [releases page](https://github.com/zuramai/mazer/releases).  
Open the index HTML file and explore the source code.

### Building yourself
```sh
# 1. Clone the repository
git clone https://github.com/your-username/mazer

# 2. Install dependencies
npm install   # or yarn install

# 3. Run locally
npm run dev

# 4. Open in browser
http://localhost:5173/
